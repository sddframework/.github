## What changes and why

Describe the problem and the resulting behavior. Link a related issue or
discussion when one exists.

## Verification

State what you checked, how you checked it, and any remaining limits. For a
documentation change, a careful review may be sufficient. For a behavior change,
include the relevant reproduction or checks; distinguish local checks from
hosted or production evidence.

- [ ] Documentation and examples match the current project status.
