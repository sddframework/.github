# Security reports

If you find a security problem in an SDDFW repository, use **Security → Report
a vulnerability** in that repository to send a private report through GitHub.
Do not put exploit details, credentials, or private information in a public issue.

Include the affected repository and commit, a minimal reproduction, expected
impact, and any relevant redacted evidence. The primary maintainer,
[@alfoncode](https://github.com/alfoncode), reviews reports.

SDDFW is in early development. Its v0.1 source preview is available for review;
there is no supported framework release or security-response service-level
agreement yet. Ordinary functional bugs and documentation problems belong in
public issues.
