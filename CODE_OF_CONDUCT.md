# Community code of conduct

SDDFW welcomes contributors with different backgrounds, experience levels,
languages, and tools. Treat each other with respect in issues, discussions,
reviews, and other project spaces.

- Discuss ideas and code without personal attacks.
- Give actionable feedback and allow people to ask questions.
- Avoid harassment, discriminatory language, threats, and sexualized conduct.
- Do not publish another person's private information without their consent.
- Keep contributions relevant; do not spam project spaces.

The primary maintainer, [@alfoncode](https://github.com/alfoncode), moderates
official project spaces. Depending on severity and repetition, moderation can
include a request to change behavior, removal of content, or a temporary or
permanent restriction on participation.

Use GitHub's **Report content** option for harmful content that requires private
reporting. Do not reproduce private information or harassment in a public issue.
For an ordinary disagreement about a project decision, discuss the decision
constructively in the relevant thread.
